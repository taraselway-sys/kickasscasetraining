# Kickass Case Builder — training copy

A copy of kickasscase.netlify.app with a fictional sample case (Jenna Caldwell) already filled in, for filming tutorials.

- Passcode screen: a simple screen to keep casual visitors out. Not real security.
- Add `?reset=1` to the address to restore the sample case after a take.
- `sample-evidence/` holds five fictional documents, each marked as a sample.

Every person, employer, address and document here is made up. Delete this site when filming is done.
